C. DESKRIPSI MASALAH
program ini dibuat untuk menghitung luas persegi panjang berdasarkan nilai panjang dan lebar yang dimasukan oleh pengguna


D. TUJUAN PROGRAM

membantu pengguna menghitung luas persegi panjang cepat dan tepat

E. ANALISIS INPUT, PROSES, DAN OUTPUT

1. INPUT:
   - input panjang persegi panjang (p)
   - input luas persegi panjang (l)

2. PROSES:
   - perhitungan luas persegi panjang
   - umus luas persegi panjang

3. OUTPUT:
   - tampil hasil luas persegi panjang

F. ALGORITMA / PSEUDOCODE
    

MULAI

   3. input nilai lebar persegi panjang
